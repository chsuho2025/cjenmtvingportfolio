# 미디어 파일 위치

작업별 폴더를 만들어 넣고, data.js 에 경로를 적으세요. (예: `assets/media/antiframe/card.jpg`)

| 용도 | 권장 규격 |
|---|---|
| 카드 이미지 | 정사각형 1200×1200 이상, jpg/webp |
| 카드 무음 영상 | 3~6초, 720px, 2MB 이하 mp4 + 첫 화면 이미지(poster) |
| 완성·소개 영상 | 원본 비율 그대로 mp4(H.264), 크면 유튜브·비메오 임베드 |
| 영상 첫 화면 이미지 | 영상과 같은 비율 jpg |
| 전후 비교 이미지 | 두 장이 같은 크기·같은 구도 |
| 전후 비교 오디오 | 같은 구간, 같은 길이 mp3/m4a |
| 과정 스틸컷 | 가로 1600px 내외 jpg/webp |
